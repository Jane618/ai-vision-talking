# 移动端适配设计文档

## 1. 目标

- Web 手机浏览器：优化 ≤640px 屏幕下的 UI 和交互体验
- Capacitor 原生打包：支持 Android/iOS App 构建
- 桌面端（>640px）：保持现有两栏布局不变

## 2. 移动端布局方案：Tab 切换 + 底部固定输入栏

```
┌─────────────────────────┐
│  Header（标题+主题切换）  │
├─────────────────────────┤
│  [摄像头] [对话]          │  ← Tab 栏
├─────────────────────────┤
│                         │
│   Tab 内容区             │
│   （全宽，flex:1，可滚动）  │
│                         │
├─────────────────────────┤
│  3次·512tok·¥0.03       │  ← 精简统计栏
├─────────────────────────┤
│  [🎤][输入框........][➤]  │  ← 固定输入栏
└─────────────────────────┘
```

关键点：
- 输入栏始终固定在底部，任何 Tab 下都可发送
- 摄像头 Tab：全宽画面 + 底部控制
- 对话 Tab：全屏对话历史
- Token 统计精简为一行，点击展开详细

## 3. 组件改造

### 3.1 App.tsx

- 新增 `activeTab` state（'camera' | 'chat'）
- 移动端（≤640px）：渲染 Tab 栏 + 单个 Tab 内容
- 桌面端（>640px）：保持双栏布局，Tab 逻辑不生效
- 输入栏从 ChatHistory 中提取到 App 级别（移动端固定在底部）

### 3.2 CostStats

- 移动端默认显示精简模式：`N次 · Ntok · ¥N.NN`
- 点击展开为 2x2 网格详细统计
- 对话 Tab 切换时自动收起

### 3.3 ChatHistory

- 移动端：移除内置输入栏（由 App 提供）
- 头部按钮文字缩短
- 气泡 max-width 放宽到 92%

### 3.4 VideoPreview

- 移动端：缩略图缩小到 80px
- 底部控制栏紧凑布局
- 场景/质量下拉 max-width 缩小

### 3.5 Lightbox（全屏大图）

- 新增右上角关闭按钮（手机没有 Escape 键）

## 4. CSS 断点策略

| 断点 | 范围 | 布局 |
|------|------|------|
| >960px | 桌面 | 双栏平分 |
| 641-960px | 平板 | 双栏堆叠 |
| ≤640px | 手机 | Tab 切换单栏 |

## 5. Capacitor 配置

- capacitor.config.ts 已有基础配置
- 需初始化 Android/iOS 平台：`npx cap add android` / `npx cap add ios`
-StatusBar、Keyboard、Haptics 插件在 App 启动时初始化

## 6. PWA 支持

- 添加 manifest.json（应用名、图标、主题色）
- Service Worker 缓存静态资源
- 后端 API 请求不缓存

## 7. 未来优化

- **扑克牌叠放滑动切换**：摄像头/对话两个面板做成可左右滑动切换的卡片，有层级深度和弹性动画效果（类似 Tinder 卡片堆叠）。需要引入手势库或自定义 touch 事件处理，实现卡片位移、旋转、缩放的物理动画。
